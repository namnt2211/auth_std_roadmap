Kiến thức đầu vào chung

Nên có trước

  • HTTP request/response, headers, status codes.
  • HTTPS/TLS ở mức khái niệm.
  • Client–Server architecture, REST API.
  • Web application và API hoạt động như thế nào.
  • Database, user/account, role/permission cơ bản.

Cho phần Lab

  • .NET SDK (bản LTS hiện hành).
  • Docker Desktop.
  • Biết tạo project ASP.NET Core Web API cơ bản.

Không cần biết trước OAuth, OIDC, SAML hay mật mã học chuyên sâu.

Kết quả đầu ra tổng thể

Sau khi hoàn thành lộ trình, người học có thể:

  1. Phân biệt Identification, Authentication, Authorization, Accounting và Federation. → M01
  2. Giải thích vai trò của IdP, Client, Relying Party, Service Provider, Authorization Server và Resource Server. → M01, M03
  3. Giải thích session, cookie, access token, ID token, refresh token, JWT, opaque token, API key và các HTTP authentication scheme (Basic, Bearer). → M02
  4. Mô tả các luồng OAuth 2.0 quan trọng, đặc biệt Authorization Code + PKCE và Client Credentials. → M03
  5. Giải thích OIDC bổ sung lớp xác thực danh tính trên OAuth 2.0 như thế nào. → M03
  6. Mô tả SAML SSO đủ để đọc flow và trao đổi với đội triển khai. → M04
  7. Phân biệt LDAP, Active Directory, Kerberos, NTLM, RADIUS, FIDO2 và WebAuthn. → M05
  8. Phân biệt Authentication và Authorization; hiểu RBAC, ABAC, ACL. → M06
  9. Nhận diện rủi ro phổ biến liên quan đến mật khẩu, session, token, redirect và cấu hình giao thức. → M06
  10. Phác thảo kiến trúc xác thực cho Web, Desktop, Mobile, API và service-to-service. → M07
  11. Đọc log/trace và khoanh vùng lỗi xác thực thường gặp. → Lab, M07
  12. Trình bày lại kiến thức cho team bằng sơ đồ, ví dụ và câu hỏi kiểm tra. → Phụ lục
  13. Dựng demo ASP.NET Core Web API xác minh JWT access token từ IdP thực (Keycloak/Entra ID) và client dùng Authorization Code + PKCE; tái hiện và giải thích lỗi 401/403. → Lab
