Module 02 — Cryptography, Session, Token & HTTP Auth Schemes

Module này trả lời 3 câu hỏi: (1) Những công cụ mật mã nào nằm sau token, chữ ký số và HTTPS — bạn chỉ cần biết mỗi cái để làm gì, không cần toán. (2) Sau khi bạn đăng nhập, ứng dụng ghi nhớ bạn bằng cách nào (session, cookie, token)? (3) Client trình “giấy tờ” cho API ra sao (Basic, Bearer, API key)?

⏱ Full 2 giờ · Core 1.5 giờ 📥 Input: Module 01, đọc được HTTP header ➡️ Tiếp theo: Module 03 — OAuth/OIDC
Sau module này bạn sẽ
  • Phân biệt chắc chắn encoding (Base64) ≠ encryption (mã hóa) ≠ hash (băm) ≠ password hashing ≠ digital signature (chữ ký số) ≠ HMAC — biết ai giữ key gì, cái nào đảo ngược được, và khi nào dùng cái nào.
  • Giải thích được vì sao không được lưu mật khẩu bằng SHA-256(password), và cấu hình password hashing theo khuyến nghị OWASP hiện hành.
  • Hiểu cookie ≠ session (cookie là “túi đựng”, session là “trạng thái đăng nhập”), stateful vs stateless, và ý nghĩa từng thuộc tính cookie (HttpOnly, Secure, SameSite…).
  • Phân biệt access token (vé gọi API) / ID token (thông tin “ai vừa đăng nhập”) / refresh token (vé để xin vé mới); đọc được một JWT và biết API phải kiểm tra những gì trước khi tin nó.
  • Mô tả vòng đời token: hết hạn, xin token mới (refresh rotation), phát hiện token bị dùng lại (reuse detection), đổi key ký (key rotation), hỏi trạng thái token (introspection), thu hồi (revocation).
  • Đọc được header Authorization / WWW-Authenticate; so sánh API key, Basic, Bearer và OAuth Client Credentials.
🎯 Mục tiêu module Cuối module, bạn làm được 3 việc cụ thể:
  1. Dán một JWT mẫu vào widget, đọc từng phần và nói được phần nào ai cũng đọc được, phần nào chứng minh “không bị sửa”.
  2. Giải thích bằng lời các bước hr-api kiểm tra một access token trước khi trả bảng lương.
  3. Vẽ được vòng đời cơ bản của một session (hr-web) và một token (hr-api): tạo → dùng → hết hạn → hủy.
Module này là “bảng chữ cái” cho OAuth/OIDC ở Module 03 — thiếu nó, bạn sẽ đọc M03 như đọc tiếng nước ngoài.

Input trước module

Bạn cần sẵn những thứ sau (chưa có thì ôn lại trước, mất khoảng 15–30 phút):

  • Hoàn thành Module 01: biết Identity là gì, AuthN (xác thực — “bạn là ai?”) khác AuthZ (phân quyền — “bạn được làm gì?”), và các vai trò IdP/RP/AS/RS.
  • Đọc được một HTTP request/response thô: dòng đầu (GET /payroll HTTP/1.1), các header, body. Đặc biệt nhận ra header Cookie, Set-Cookie, Authorization. Cách nhanh nhất: mở DevTools (F12) → tab Network → bấm vào một request bất kỳ.
  • Biết sơ bộ HTTPS là “HTTP chạy trên kênh được mã hóa” (ổ khóa trên thanh địa chỉ). Chi tiết TLS sẽ học ở bài 2.1.
  • Không cần biết toán mật mã, không cần biết OAuth.
💡 Ví dụ xuyên suốt: tiếp tục hệ thống “Kaopiz HR”
  • hr-web: web app ASP.NET Core mà nhân viên An dùng trên trình duyệt (dùng session cookie).
  • hr-api: Web API trả dữ liệu bảng lương (nhận Bearer access token).
  • Keycloak realm kaopiz tại https://sso.kaopiz.local/realms/kaopiz: Identity Provider + Authorization Server cấp token.
  • payroll-batch: job chạy đêm gọi hr-api (service-to-service, không có người dùng).

Các bài trong module

Học lần lượt từng bài (mỗi bài một lần ngồi), cuối cùng làm trang Ôn tập & Quiz. Thanh điều hướng đầu mỗi trang cho biết bạn đang ở đâu trong module.

  1. Bài 2.1 — Cryptography essentials · ~30 phút
    Encryption, hash, password hashing có salt, chữ ký số, HMAC, certificate/PKI và TLS — mỗi công cụ giải quyết bài toán gì.
  2. Bài 2.2 — Session, Cookie & session management · ~20 phút
    Cookie ≠ session, stateful vs stateless, thuộc tính cookie, session fixation, timeout, remember me và logout.
  3. Bài 2.3 — Token & JWT · ~20 phút
    Access / ID / refresh token, opaque vs JWT, cấu trúc JWT và checklist API phải kiểm tra trước khi tin một access token.
  4. Bài 2.4 — Vòng đời token · ~10 phút
    Hết hạn, refresh rotation, reuse detection, key rotation, introspection và revocation.
  5. Bài 2.5 — HTTP auth schemes & API key · ~15 phút
    Header Authorization / WWW-Authenticate, Basic, Bearer, API key — và khi nào dùng cái nào.
  6. Ôn tập & Quiz · ~15 phút
    Hiểu lầm cần tránh, tóm tắt, deliverables, knowledge check và quiz trắc nghiệm.
